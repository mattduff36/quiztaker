# Vitriol whole-repository audit — 3 November 2026

Scope: hosted routes and UI, shared core, local helper, browser executors,
legacy dashboard, stored outcomes/memory, dependencies, packaging and release
workflows. This is a source and behavior audit, not a guarantee of no defects.

## Findings and changes

| --- | --- | --- |

## Cleanup and retained functionality

Removed the obsolete local Cursor SDK adapter and its dependency, configuration,
fallback branches and obsolete tests/documentation. Personal OpenAI, Gemini,
OpenRouter and inherited HTTP provider connections remain.

Removed `pw-course-fast-complete.js` (superseded by the SCORM1.2/2004 executor),
`pw-fit-viewport.js` (duplicate viewport utility) and `kill-quiz-procs.js`
(obsolete broad process-kill path). Reference search found no live callers.
The supported replacements are `pw-scorm-complete.js`, `pw-fit-tab.js` and
helper-owned cancellation/recovery.

The legacy local dashboard retains useful HP/Saba/manual workflows. Its public
capabilities and execution routes no longer advertise/accept the hosted AI
learner because the legacy server has no proposal bridge. The shared hosted
registry remains intact. Other documented timed-assessment helpers still have
real uses and were retained; source age alone was not a removal criterion.

All site routes were inspected: Operations, helper/pairing/download, History,
Learning/review/player knowledge, Runbooks, Settings/AI tools and sign-in/out.
API ownership/origin checks, signing/capability boundaries, private artifacts,
idle protection, update progress, course coverage, database migrations and CI
were retained. No authentication/security protections were weakened.

benchmark): accessibility3/4, performance3/4, responsive behavior3/4,
theming2/4, implementation integrity3/4: **14/20, Good**. The incumbent light

Keyboard/focus, labels, disabled/loading/error states and mobile flow were
checked. Lifecycle/reliability findings above are P1; remaining usability/copy
findings are P2. No P0 issue was established.

The UI detector reported two gray-on-color warnings. Both were reviewed:
the brand mark deliberately uses near-black text on cyan; Generate code uses
white on cyan, with gray text only in its disabled gray-background variant.
These are detector context/variant false positives, not observed contrast bugs.
Duplicate helper-update banners were removed; update recovery remains
available while the course session is paused.

## Limits

Manual task completion is explicitly operator reported; it never fabricates a
verified LMS pass or promotes a strategy. The helper must acknowledge stopping
before new work is admitted. The recorded Canon task was closed using the
operator-confirmed visible75% pass; no new course attempt is needed for QA.

The earlier native Windows `0xC0000409` child exit was not conclusively diagnosed.
Identical signed Node binaries and successful subsequent refreshes do not prove
a binary defect. Duplicate/lifecycle races are fixed; if the native crash
recurs, collect exact process/crash evidence rather than disabling safeguards.
